# eIsland 本地版功能说明

## 使用自己的 AI API

1. 打开“设置 → AI 配置 → 通用配置”。
2. 填写 OpenAI 兼容的 API Endpoint、API Key 和模型名称。
3. 在 AI 对话模型列表中选择 `custom-api`。
4. 调用模式选择“直连”后，请求只在本机和所配置的模型服务之间传输，不需要登录 eIsland，也不要求 PRO 订阅。

也可以在“Ollama 本地”页面自动检测 Ollama，并选择已经下载的模型。Ollama 模式不需要登录、API Key 或订阅。

API Key 不会进入本地工作台导出的备份文件。

## 本地工作台

在最大展开页面选择“本地工作台”，或按 `Ctrl+K` 打开。

- 快捷命令：搜索并打开已有模块，也可以运行声明式插件提供的命令。
- 通知中心：在本机保存最近 200 条岛内通知。
- 备份恢复：导出和恢复常用本地数据，自动排除账号令牌、密码和 API Key。
- 自动化：按每天指定时间发送提醒，支持启停、手动运行和删除。
- 智能剪贴板：保存常用文本片段；疑似密码、JWT 和长令牌会被阻止。
- 邮件助手：收件箱全文搜索、后台检查间隔和新邮件提醒。
- 专注模式：可调整时长的本地专注计时器。
- 本地插件：导入声明式插件清单，不执行第三方 JavaScript。
- 日历：保存本地日程，并在开始时提醒。
- 本地同步：生成不包含敏感凭据的同步快照，可通过加密盘、NAS 或同步文件夹传递。

## 声明式插件格式

```json
{
  "id": "system-info",
  "name": "系统信息",
  "version": "1.0.0",
  "description": "提供系统信息快捷命令",
  "commands": [
    {
      "id": "info",
      "title": "查看系统信息",
      "tool": "sys.info",
      "arguments": {}
    }
  ]
}
```

插件只能引用 eIsland 已有的本地工具。涉及文件删除、关机重启、注册表、服务、代理等高风险操作时，客户端仍会要求确认。
